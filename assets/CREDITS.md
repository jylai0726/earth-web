# 素材来源与署名 / Credits

## 天体纹理

本项目 `assets/` 下的天体表面纹理来自 **Solar System Scope**：

- 来源：<https://www.solarsystemscope.com/textures/>
- 许可证：[Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/)
- 使用方式：作为 Three.js 材质的贴图，经实时光照、昼夜混合与着色显示；构建时按显示尺寸缩放并内嵌进 `index.html`。

| 文件 | 用途 |
| --- | --- |
| `earth-day.jpg` | 地球日照面 |
| `earth-night.jpg` | 地球夜面城市灯光 |
| `earth-clouds.jpg` | 地球云层 |
| `moon.jpg` | 月球 |
| `sun.jpg` | 太阳表面 |
| `mercury.jpg` | 水星 |
| `venus-atmosphere.jpg` | 金星云顶 |
| `mars.jpg` | 火星 |
| `jupiter.jpg` | 木星 |
| `saturn.jpg` | 土星 |
| `saturn-rings.png` | 土星环（含透明度） |
| `uranus.jpg` | 天王星 |
| `neptune.jpg` | 海王星 |
